Documents and PDFs

Keep each client’s files in one place, collect files from clients, and make PDFs.

The client’s documents

Every client has a document vault, filed by year and filing (for example GSTR-1 for October). Files are checked for viruses, and the same file can’t be stored twice. Files CaDesk makes, such as a GSTR-1 JSON or a PDF report, can be saved straight into the vault.

Collecting files from clients

Create an upload link from the client’s documents and send it to the client. They can upload without an account until the link expires or reaches its file limit, and they see what has arrived.

PDFs

In the audit workspace, the audit dossier and the independent auditor’s report have Download PDF and Save PDF to client documents. The PDF has bookmarks for each section, page numbers and, for the dossier, the start of its SHA-256 seal in the footer.
