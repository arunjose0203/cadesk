Report a problem

Tell us when something goes wrong, so we can fix it quickly.

  1. Choose the flag button at the bottom of the sidebar (Report a problem).
  2. Say what you were doing and what happened. Please don’t include clients’ PAN, Aadhaar or bank details.
  3. Keep Attach technical details ticked: it adds the desk you are on and the last errors the app saw, which usually shows us the cause.
  4. You get a reference such as PR-1A2B3C4D. Quote it if you call or write to us.

When the app itself fails (a desk that won’t open, a server error), it reports this automatically. Server error messages end with a reference such as E-0000ABCD12; quote that too.
